# 保存动态和文章

在详情页右上角，点击三个点左侧的“保存内容”图标，选择格式，再通过系统文件选择器指定位置和文件名。

| 格式 | 适用场景 | 图片 |
| --- | --- | --- |
| Markdown（.md） | 编辑、笔记、归档 | 保留在线链接 |
| 离线 HTML（.html） | 用浏览器阅读图文 | 内嵌至同一个文件 |

保存完整正文、作者、发布时间、来源链接、已有转发内容，以及最多三条一级评论。置顶评论最先，其余按酷安服务端的“热门”顺序补足，同一条不重复；遵守本地用户屏蔽。不改变详情当前评论排序，不展开楼中楼。

保存时会单独读取热门评论。读取失败或需要验证时明确提示，可以取消并在评论区完成验证后重试，也可以确认继续保存已取得的内容；文件中会保留缺失说明。

HTML 优先使用已有图片缓存，再尝试下载。图片只接受可解码的 PNG、JPEG、GIF、WebP；单张最多 8 MiB、解码尺寸最多 32 MP、累计最多 32 MiB、最多 60 张，图片准备时间约 45 秒上限。图片失败或超限时须确认继续，文件以“图片未保存”来源链接替代，不能离线查看缺失的图片。HTML 不依赖外部样式和脚本，也不会主动加载外部图片。

当前首版在独立 M3E 测试分支，未合入或发布。PDF、视频文件、全量评论和楼中楼不在本轮范围。页内目录锚点暂不保证保留；普通来源链接保留。Markdown/HTML 以便于阅读的正文结构保存，不是应用界面的像素截图。
