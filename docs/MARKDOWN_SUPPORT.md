# 基础 Markdown（测试分支）

帖子正文会自动识别 Markdown，普通动态与图文文章均适用。更新弹窗的说明直接按 Markdown 显示。评论和私信继续使用原有显示方式。

首版支持常用的 GitHub README 写法：

- `# 标题` 至六级标题、加粗、斜体、删除线。
- 引用、有序/无序列表、嵌套列表、分隔线。
- 行内代码和围栏代码块；代码中的表情、空格及标签原样显示。
- 链接、HTTP(S) 图片、表格、只读任务列表。
- 标题锚点，以及酷安原生话题、用户和动态链接。

长代码与宽表格可横向滚动。信息流和转发卡片显示限行预览，进入详情阅读完整内容。识别到 Markdown 后，详情右上角菜单可切换“查看原文”与“格式化显示”；显示转换不回写帖子、历史或收藏的原始文本。

酷安内容中的特定 `<!--break-->` 显示分隔标记在格式化时隐藏，原文仍保留；这一处理不应用于更新日志，也不删除其他 HTML 注释。

自动识别采用保守规则。单独的话题 `#一加13#`、型号 `POCO_X3_GT`、一个普通编号或孤立标点不会触发；含义不明确的单项列表可能保留原样。原文入口用于处理作者未打算使用 Markdown 的情况。

此版本不承诺完整复刻 GitHub：不执行任意内嵌 HTML，不支持公式、Mermaid 图形、语法高亮、脚注或可交互任务项。任意本地文件/资源 URL 不作为正文图片加载。超出解析长度限制或转换失败时保留可读原文。

语法参考：[GitHub Flavored Markdown](https://github.github.com/gfm/)。解析采用锁定的 Dart `markdown`，第三方许可见 [第三方声明](THIRD_PARTY_NOTICES.md)。
